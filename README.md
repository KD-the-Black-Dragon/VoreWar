# VoreWar
This game is a continuation of darkevilme's game Vore War. It is a turn based tactical game with rpg elements in a vore related world.

Check out [The Eka's thread](https://aryion.com/forum/viewtopic.php?f=79&t=65398) by @Flame_Valxsarion for more information on the original Vore War! 

This fork is developing a mercenary-company total conversion. Completed fork changes are recorded with dates in [CHANGES.md](CHANGES.md); planned work is described in the [conversion roadmap](docs/conversion-roadmap.md). The applicable GNU GPL version 3 terms are included in [License.txt](License.txt), and existing upstream attribution and notices are retained.

## Play the company proof of concept

Open the project in Unity 2018.3.12f1, open `Assets/base.unity`, enter Play mode and select **New Campaign**. Create your leader, hire a couple of starters in the town, equip them and take local contracts. **Help** opens the shared blue campaign guide, with compact chapters and a scrollable reading area. New Campaign offers company creation and Load Game without the retired Continue/map-preview entries. Use the persistent **Contracts / Company / Map / Town / Records** buttons to switch views. Drag the centered map with the left or middle mouse button; **Center company** brings the company back into view. New regions are80x60tiles with six towns; old saves keep their existing map. Campaign leader revival is available in normal **Options**. Options groups preferences into one centered, scrollable blue panel; the Campaign category appears only when a company is active. Content Settings uses the same blue styling, with its page dropdown at the top and a scrollable column on each page. Town services stay in the left column, and ready members can level up directly from the roster. Rest requires a full daily action budget; **End turn** remains separate. **Single Battle** opens the separate tactical setup, with core controls at the top and Attackers/Defenders in independently scrollable columns with species previews. **Load Game** on the main menu opens the company Save / Load browser. Traveling outside towns can now trigger wild Spitter Slug combat or a practice-duel request from healthy mercenaries.

Company Save / Load supports named manual slots, progress previews, confirmed deletion and map/battle autosaves with three recovery backups per slot. Normal company battles can be saved while ready to act on your own turn and resume that exact battlefield. Ironman uses its latest valid autosave and invalidates/removes its saves when the company ends. Original empire saves remain unsupported. Balance remains provisional. See the [integrated review](docs/implementation/12-integrated-review-and-help.md) and [release-readiness record](docs/release-readiness.md) for performed checks, pending graphical player/combat coverage and inherited provenance/distribution gates. No release is declared by this proof of concept.


## Standalone Windows testing

The current local build is in `Builds/Warband-Review-20261103-edb0c0f0/Win64/`. Open **VoreWar.exe** to launch normally. Unity Editor is not required. Keep the whole folder together, including VoreWar_Data, UnityPlayer.dll and MonoBleedingEdge. The older MVP-Review build predates the current UI/rendering changes.

To make a later build yourself in Unity2018: stop Play mode, choose **File > Build Settings**, select **PC, Mac & Linux Standalone**, **Windows**, **x86_64**, and ensure **Assets/base.unity** is checked in Scenes In Build. Choose **Build** (or **Build And Run**) and select a new folder under this project's Builds directory. The saved MultiBuild output path still refers to the original developer's desktop; the current agent build overrides it explicitly. Building does not publish the game. The current private build includes license/notices; release/distribution reviews remain separate.

# VoreWar
This game is a continuation of darkevilme's game Vore War. It is a turn based tactical game with rpg elements in a vore related world.

Check out [The Eka's thread](https://aryion.com/forum/viewtopic.php?f=79&t=65398) by @Flame_Valxsarion for more information on the original Vore War! 

This fork is planning a mercenary-company total conversion. Completed fork changes are recorded with dates in [CHANGES.md](CHANGES.md); planned work is described in the [conversion roadmap](docs/conversion-roadmap.md).

# VoreWar
This game is a continuation of darkevilme's game Vore War. It is a turn based tactical game with rpg elements in a vore related world.

Check out [The Eka's thread](https://aryion.com/forum/viewtopic.php?f=79&t=65398) by @Flame_Valxsarion for more information on the original Vore War! 

This fork is developing a mercenary-company total conversion. Completed fork changes are recorded with dates in [CHANGES.md](CHANGES.md); planned work is described in the [conversion roadmap](docs/conversion-roadmap.md). The applicable GNU GPL version 3 terms are included in [License.txt](License.txt), and existing upstream attribution and notices are retained.

## Play the company proof of concept

Open the project in Unity 2018.3.12f1, open `Assets/base.unity`, enter Play mode and select **New Campaign**. Create your leader, hire a couple of starters in the town, equip them and take local contracts. **Campaign help** explains the current rules and saving. Use the persistent **Contracts / Company / Map / Town / Records** buttons to switch views. Drag the centered map with the left or middle mouse button; **Center company** brings the company back into view. New regions are80x60tiles with six towns; old saves keep their existing map. Campaign leader revival is available in normal **Options**. Options groups preferences into one centered, scrollable blue panel; the Campaign category appears only when a company is active. Content Settings uses the same blue styling, with its page dropdown at the top and a scrollable column on each page. Town services stay in the left column, and ready members can level up directly from the roster. Rest requires a full daily action budget; **End turn** remains separate. **Single Battle** opens the separate tactical setup, with core controls at the top and Attackers/Defenders in independently scrollable columns with species previews. **Load Saved Game** on the main menu opens the company checkpoint list. Traveling outside towns can now trigger wild Spitter Slug combat or a practice-duel request from healthy mercenaries.

Company saves use their own checkpoint list. Live company battles resume from the saved deployment checkpoint when interrupted, rather than the last tactical turn. Balance remains provisional. See the [integrated review](docs/implementation/12-integrated-review-and-help.md) and [release-readiness record](docs/release-readiness.md) for performed checks, pending graphical player/combat coverage and inherited provenance/distribution gates. No release is declared by this proof of concept.
